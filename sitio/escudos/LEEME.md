# Escudos

Un archivo SVG por grupo del lente «Escuelas y facultades» (`compartido/facultades.js`);
el nombre del archivo es el `key` del grupo (`medicina`, `fes-aragon`, `uvm`, ...).

Los archivos actuales son **monogramas generados** (disco en el color del grupo + siglas):
marcadores provisionales con una identidad visual consistente y sin problemas de licencia.

Para usar el escudo oficial de una facultad/escuela basta reemplazar el SVG conservando el
nombre del archivo — el mapa lo toma tal cual, sin cambios de código (viewBox 0 0 64 64
sugerido; el marcador lo recorta en círculo, así que funciona mejor un emblema centrado).
Los escudos oficiales son marcas de cada institución: NodOS es un proyecto independiente
y no oficial, así que conviene citar la fuente de cada imagen que se incorpore.
